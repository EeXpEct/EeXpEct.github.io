00 / SHARED FOUNDATION

不论走哪条路，先把底座装好。

不是所有方向都需要先精通这四项，但它们是最常复用的能力。未来换方向时，你已经学过的东西不会白费。

01 / NETWORK

计算机网络

IP、TCP/UDP、DNS、HTTP；理解数据从一台机器怎样到达另一台。

02 / SYSTEM

操作系统

Linux 命令行、Windows 基础、进程、文件、权限和内存。

03 / CODE

编程与脚本

先用 Python 做自动化；再根据方向学习 C/C++、JavaScript 等。

04 / THINK

安全思维

问题拆解、假设验证、查资料、记笔记、复现实验、写清结论。

⚑把技能树当成探索地图，而不是必须依次解锁的游戏关卡。分支之间可以交叉；“终点技能”只是可能发展出的能力，不是学完几节课就能自动获得的资格。

如何安排学习顺序？

先学共同基础，然后挑一个领域做小项目。不必同时冲刺三个方向。

05 / YOUR FIRST 4 WEEKS

零基础也可以，从今天开始。

一个适合社团新人的通用 4 周试水计划。可以跟自己的课程和时间安排调整节奏，重点是每周做出看得见的东西。

WEEK 01 / KNOW THE SYSTEM

认识自己的电脑

终端、目录、进程、权限；用虚拟机体验 Linux，学会排查一个简单故障。

交付物： 一份命令行速查表
WEEK 02 / SEE THE NETWORK

看懂一次访问

用浏览器开发者工具和 Wireshark 观察 HTTP / DNS，理解客户端与服务器。

交付物： 一份请求路径分析
WEEK 03 / MAKE A TOOL

编程解决小问题

从 Python 变量、判断、循环、函数开始，写一个处理日志或文件的小脚本。

交付物： 一个可运行的 Python 程序
WEEK 04 / PICK A PATH

做一件安全小事

任选一个方向的入门靶场、题目或公开样本，在合法环境里验证学到的知识。

交付物： 一篇图文复盘报告

06 / VERIFIED LEARNING SOURCES

从这些可靠的入口出发。

优先官方文档、免费练习平台和开源教学项目。点击跳转到原站；在线资源需要联网，网页其余部分可离线使用。
